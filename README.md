# SCZ gut mycobiome downstream analysis code

English | 中文

This repository contains the downstream analysis code for the schizophrenia gut mycobiome reanalysis. The workflow starts only from the five supplied input files under `data/metadata/`. All standardized metadata tables, processed abundance matrices, differential abundance results, network tables, and random-forest outputs are generated by the scripts.

本代码包用于精神分裂症肠道真菌组再分析的下游统计分析。流程从 `data/metadata/` 中提供的 5 个输入文件开始，自动生成标准化 metadata、处理后丰度矩阵、差异丰度结果、网络表和随机森林输出。

## Input files

The only required input files are:

```text
data/metadata/sample_map
data/metadata/sample_info.xlsx
data/metadata/fungi.profile
data/metadata/fungi.profile.genus
data/metadata/bacteria_species.profile
```

`sample_map` contains sample IDs and group labels. `sample_info.xlsx` contains sample-level demographic, clinical, sequencing, and follow-up metadata. The three profile files are the fungal species-level, fungal genus-level, and bacterial species-level abundance matrices.

`sample_map` 包含样本 ID 和分组信息；`sample_info.xlsx` 包含样本层面的基本信息、临床信息、测序质控信息和随访信息；三个 profile 文件分别是真菌 species、真菌 genus 和细菌 species 丰度矩阵。

Follow-up IDs are standardized automatically. For example, `ERR2855788.t2` in `sample_map` is converted to `ERR2855788-t2` to match the abundance matrix column names.

## Preparation step

Run this first:

```bash
Rscript code/01_prepare_inputs.R
```

This script generates the downstream working files listed below. These are generated files, not files that need to be supplied manually:

```text
data/metadata/sample_map_baseline.tsv
data/metadata/sample_map_all.tsv
data/metadata/clinical_metadata.tsv
data/processed/fungi.profile.species.tsv
data/processed/fungi.profile.genus.tsv
data/processed/bacteria.profile.species.tsv
data/random_forest/fungi_features.tsv
data/random_forest/bacteria_features.tsv
data/random_forest/merged_features.tsv
```

Do not provide these generated files separately unless you intentionally want to reuse existing outputs. They can be regenerated from the five supplied input files above.

## Run order

Run commands from the repository root.

```bash
Rscript code/01_prepare_inputs.R
Rscript code/wilcoxon_daa.R
Rscript code/alpha_diversity.R
Rscript code/PCoA.R
Rscript code/network.R
Rscript code/marker_boxplot.R
bash code/randomforest.txt
Rscript code/plot_randomforest_results.R
```

Optional MaAsLin2 sensitivity analysis:

```bash
Rscript code/maaslin2_sensitivity.R
```

## Notes

The repository starts from the supplied abundance profiles and sample metadata. Raw-read preprocessing, host/prokaryotic/rRNA depletion, MetaPhlAn4 bacterial profiling, fungal read mapping, and fungal abundance normalization are described in the manuscript Methods. The downstream scripts in this repository regenerate the statistical outputs from the supplied abundance profiles and metadata.

本代码包从处理后的丰度矩阵和样本 metadata 开始。原始 reads 质控、宿主/原核/rRNA 去除、MetaPhlAn4 细菌 profiling、真菌 reads 比对和真菌丰度标准化方法已在论文 Materials and Methods 中描述。本仓库的脚本用于从这些输入表重新生成下游统计分析结果。
